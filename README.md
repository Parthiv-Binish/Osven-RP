# 🌆 Osven City

Premium FiveM Roleplay Server — built on QBCore.

## 🚀 Quick Start

1. **Clone** this repository
2. **Import** `database/migration_v1_osven_city.sql`
3. **Configure** `server.cfg` (license key, DB connection)
4. **Start** via txAdmin

## 📦 Stack

| Component | Resource |
|-----------|----------|
| Framework | qb-core |
| Database | oxmysql |
| Library | ox_lib |
| Target | ox_target |
| Inventory | qb-inventory (→ ox_inventory planned) |
| Phone | qb-phone (→ NPWD planned) |
| Voice | pma-voice |
| HUD | osven-hud (custom) |
| Loading | osven-loading (custom) |
